Wander Notes は、散歩と思索のあいだに生まれるメモを蓄積するための個人サイトです。

静的な記事本体は `wandernotes.cc` で配信し、将来的な動的機能は `api.wandernotes.cc` に分離して追加する予定です。

## 公開方針

このサイトは、最初からすべての機能を作り込むのではなく、まずは公開できる静的ブログを先に整える方針で作っています。

将来的には Rust + Cloudflare Workers による API を別サービスとして追加し、以下のような機能を扱います。

- お問い合わせ
- 閲覧数・いいね
- 散歩記録 API
- 検索・AI 機能
